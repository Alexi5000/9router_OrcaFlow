# Managed local configuration

The dashboard intentionally writes operator-selected settings into the supported CLI configuration files, translator fixtures and tunnel state. Management routes pass through dashboardGuard: login is required unless the operator explicitly disables it; foreign-origin writes are rejected even in that mode. Disabling login is appropriate only on a trusted local interface.

Managed writes use exclusive temporary files with POSIX mode 0600, followed by atomic rename; new directories use 0700. Reads/writes/deletes reject symlink and hardlink targets, special files and linked ancestors. POSIX ancestors must be owned by the process user or root and not writable by others, except root-owned sticky shared ancestors such as /tmp. A symlinked home-directory alias is resolved first. Existing normal CLI files can be migrated from broader permissions on the next successful save. No directory permissions are silently changed.

If an existing CLI configuration uses symlinks, shared writable directories or files owned by another user, the dashboard update now fails instead of following them. Use ordinary files under a private directory owned by the runtime user. The helper does not establish Windows ACL confidentiality, support hostile same-UID processes racing filesystem operations, or promise a transaction spanning both Codex config.toml and auth.json. Individual writes are atomic; any write failure returns an error. Codex serialization preserves TOML value types but may normalize formatting/comments.

The translator replay script intentionally sends the operator-selected JSON fixture URL, headers and body. Only use trusted fixtures. It redacts displayed header values and URL query/userinfo and refuses redirects; provider response bodies remain visible because this is a response-debugging tool. README translation intentionally sends README.md to the configured translation provider. MITM model routing intentionally sends a configured model alias to the fixed localhost router endpoint. These paths do not upload arbitrary files selected by unauthenticated HTTP callers.
